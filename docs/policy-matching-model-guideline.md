# 인구감소지역 유휴공간 정책매칭 모델 개발지침

> **범위 축소 안내:** 이 문서는 전국 확장형 초기 구상이다. 현재 공모전의 기준 문서는 [`sgis-uiseong-policy-proposal-guideline.md`](sgis-uiseong-policy-proposal-guideline.md)이며, 실제 분석은 의성군 전통 못 Case Study에 집중한다.

## 1. 프로젝트 목적

인구감소지역의 유휴·저활용 공간과 지역자원을 발굴하고, 지역의 인구·사회·경제 특성과 공간 조건을 결합하여 적합한 활용방안과 정책을 도출하는 데이터 기반 정책 의사결정 모델을 구축한다.

핵심 질문은 다음과 같다.

> 어떤 유휴공간을, 어떤 지역에서, 어떤 목적으로 활용하는 것이 가장 적합한가?

단순한 위치 시각화나 공간 레이어 중첩이 아니라 다음 흐름을 구현한다.

```text
지역 수요 → 유휴자원 → 공간적 적합성 → 지역 유형 → 정책 매칭 → 우선순위
```

## 2. 프로젝트 범위와 의성 사례의 역할

전체 모델의 범위는 전국 인구감소지역으로 설정한다. 의성 프로젝트는 폐기하거나 처음부터 다시 개발하지 않고, 실제 적용과 검증을 보여주는 Case Study로 사용한다.

```text
전국 인구감소지역 정책모델
        ↓
지역 수요·유휴공간·적합성 분석
        ↓
정책 매칭
        ↓
의성 전통 못 사례 적용
```

기존 의성 연구에서 재사용할 자산은 427개 못 공간데이터, 현장조사·정보공개청구 결과, QGIS 공간화, 접근성·주변 인프라 분석, 청년·관광·일자리 활용 검토, 부서 협력 모델이다. 역사·문화 설명과 개별 시설 서술은 새 공모전의 목적에 맞게 축소한다.

## 3. 핵심 분석 프레임

### 지역 수요

총인구, 청년인구, 고령인구, 인구감소율, 1인가구, 가구 특성, 사업체·종사자, 생활인구, 관광객, 생활SOC 접근성을 정책 수요 지표로 검토한다. 가능하면 SGIS 통계를 핵심 근거로 사용한다.

### 유휴·저활용 공간

빈집, 폐교, 유휴 공공시설, 폐산업시설, 폐역·역사, 저활용 관광시설, 전통 수리시설 등을 후보로 검토한다. 모든 유형을 한 번에 수집하지 않고 데이터 확보 가능성, 정책 활용성, 공간분석 가능성으로 우선순위를 정한다.

### 공간적 적합성

도로·대중교통 접근성, 생활SOC·관광자원·상권·일자리와의 거리, 주변 공공시설, 인구·가구 분포, 유휴공간 밀집도를 정책 목적별로 다르게 평가한다.

### 정책 매칭

정책을 먼저 정하지 않는다. 데이터 분석으로 지역 유형과 공간 유형을 도출한 뒤 활용정책을 매칭한다.

| 지역 수요·특성 | 유휴공간 | 정책 후보 |
|---|---|---|
| 청년인구 부족 + 접근성 양호 | 폐교 | 청년창업·정착 공간 |
| 관광자원 풍부 | 유휴시설 | 관광·체류 공간 |
| 고령인구 높음 + 생활SOC 부족 | 공공 유휴시설 | 생활지원 공간 |
| 귀촌 수요 + 빈집 밀집 | 빈집 | 귀촌·청년 정착 |
| 지역문화자원 풍부 | 전통자원 | 문화·교육·관광 |

## 4. SGIS 활용 전략

SGIS는 배경지도나 단순 통계표가 아니라 정책 판단의 근거로 사용한다. 우선 검토 대상은 인구·연령·청년·고령, 가구·세대구성, 주택·건축년도, 사업체·종사자 및 기타 지역특성 통계다.

공모전 제출에서는 다음을 명확히 설명한다.

```text
SGIS 지역통계
      ↓
지역 수요 파악
      ↓
유휴공간·지역자원 결합
      ↓
공간 적합성 분석
      ↓
활용 가능 자원 발굴
      ↓
지역 맞춤형 정책 제안
```

SGIS 생활권역 주행인구는 시설 주변 거주인구와 다른 도달 규모 지표다. 비밀보호 처리와 생활권 중복을 명시하고 시설 간 합산하지 않는다.

## 5. 모델 원칙

1. 1단계는 설명 가능한 지표 기반 모델로 구현한다.
2. 지역 수요, 공간 특성, 접근성, 주변 자원, 경제·인구 특성을 적합성 지표로 결합한다.
3. 지표 방향성, 결측 처리, 정규화, 가중치의 근거를 문서화한다.
4. AHP는 필요할 때 검토하되 방법론 자체를 성과로 삼지 않는다.
5. Random Forest 등 머신러닝은 정답 라벨의 출처와 검증셋이 확보된 뒤 별도 실험으로 진행한다.
6. 실제로 계산·검증하지 않은 정확도, F1, 우선순위 점수, 정책효과는 제출문서에 쓰지 않는다.

## 6. 개발 순서

1. 문제 정의: 공간 부족보다 지역 수요와 자원의 미스매칭에 초점을 둔다.
2. 분석 대상 확정: 인구감소지역과 유휴공간 유형을 정한다.
3. SGIS 지표 선정: 정책 판단에 필요한 최소 지표를 선정한다.
4. 지역 유형화: 인구·사회·경제 특성으로 지역을 유형화한다.
5. 유휴공간 분석: 위치, 접근성, 주변 자원, 공간 조건을 계산한다.
6. 정책 매칭: 지역 유형과 유휴공간 유형을 정책 후보에 연결한다.
7. 의성 Case Study: 기존 427개 전통 못 연구에 모델을 적용한다.
8. 공모전 제출: SGIS 활용부터 정책 도출과 사례 검증까지 서술한다.
9. Web GIS MVP: 지역·공간·수요·정책 후보를 조회한다.
10. 확장: 자동화·API·DB·Web GIS를 단계적으로 추가한다.

## 7. Python·Web GIS 역할

Python은 데이터 정제, 공간 결합, 지표 계산, 유형화, 점수화, 시각화, 반복 가능한 파이프라인에 사용한다. 불필요한 AI/ML이나 분석량 확대를 목표로 하지 않는다.

Web GIS MVP는 인구감소지역 지도, 지역 수요 지표, 유휴공간 유형, 적합성 점수, 정책 추천, 지역 비교, 상세정보를 제공한다. 지자체 담당자가 지역 선택 → 공간 선택 → 통계 확인 → 활용 유형 확인 → 정책 후보 확인의 흐름을 수행할 수 있어야 한다.

## 8. 데이터 및 검증 원칙

- 원자료, 정제자료, 분석결과를 분리한다.
- 미확보 데이터는 `DATA_NOT_AVAILABLE`로 유지한다.
- 출처, 기준연도, CRS, 라이선스, 가공방법을 manifest와 문서에 기록한다.
- 정책매칭 결과에는 사용 지표와 판단 이유를 함께 저장한다.
- 의성 자료는 Case Study용 실증 데이터로 표시하고 전국 자료처럼 일반화하지 않는다.
- 다른 지역에 즉시 적용 가능하다고 주장하기 전에 소규모 타 지역 재현 테스트를 수행한다.

## 9. 공모전 포지셔닝

### SGIS 공모전

SGIS 통계를 활용한 지역 수요 분석 → 유휴공간 결합 → 지역 맞춤형 정책 도출을 중심으로 제출한다.

### VWorld 공모전

기존 VWorld 분석은 별도 공간정보 활용 산출물로 보존한다. 필요하면 Web GIS와 공간정보 통합 기능을 확장하되, 새 SGIS 정책모델과 성과·주장을 혼용하지 않는다.

### 의성 사례

의성 전통 못은 기존 연구성과와 새로운 정책매칭 모델의 실제 적용 사례로 제시한다.

## 10. 금지사항

- 데이터 개수나 Python 코드량을 성과로 포장하지 않는다.
- 의미 없는 레이어를 계속 추가하지 않는다.
- SGIS를 단순 배경지도처럼 사용하지 않는다.
- 정책을 먼저 정하고 데이터를 맞추지 않는다.
- 의성 사례를 전국 모델과 같은 범위로 다시 개발하지 않는다.
- 검증되지 않은 AI 성능, 정책효과, 확산성을 주장하지 않는다.
- 공모전 제출을 위해 불필요하게 거대한 서비스를 만들지 않는다.

## 최종 목표

전국 인구감소지역의 `지역수요 → 유휴공간 → 적합성 → 정책` 매칭 모델, 의성 전통 못 실증사례, 분석 결과를 확인하는 Web GIS 정책 의사결정 플랫폼을 단계적으로 구축한다.
