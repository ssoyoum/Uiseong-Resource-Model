WHY THIS PROJECT

왜 '못'을 데이터로 보았는가?

문제 인식

의성에는 오래전부터 농업용수를 확보하고
공동으로 이용해 온 의성만의 고유한 전통 농업수리시설인 '못'이 존재했습니다.

의성의 농업환경과 공동체의 물 관리 방식이 담긴 이 시설들은 단순한 문화유산이 아니라,
지역의 농업 시스템과 수자원 관리의
핵심 인프라로 기능해왔습니다.

접근 방법

이 전통수리시설을
"공간 데이터로 분석할 수 있는 지역자산"
으로 바라보았습니다.

못의 위치, 규모, 용량, 관리주체 등을
데이터로 정리하고
GIS를 이용하여 공간적으로 표현했습니다.

MODEL & FIRST CASE

의성에서 검토하고,
다른 지역에 적용할 절차를 설계했습니다

자원 발굴부터 정책 제안 전 검증까지, 데이터가 설명할 수 있는 범위를 단계별로 구분합니다.

01 / 발굴

지역자원 목록화

시설 ID와 위치를 정리하고 좌표 품질을 점검합니다. 의성 사례에서는 전통수리시설 못 427개를 분석 단위로 관리합니다.

02 / 결합

SGIS 생활권 분석

5분·10분 주행생활권 인구에 읍·면 인구구조, 도로·주변시설 자료를 결합합니다. 미응답은 수요 0명과 구분합니다.

03 / 검토

정책 맥락 구분

접근·도달, 청년참여, 공동체 지원 등 6개 맥락으로 현장 검토 대상을 정리합니다. 정책 채택이나 효과 검증을 뜻하지 않습니다.

2025년 의성 청년연구에서 전통수리시설 ‘못’을 바탕으로 청년 조사·기록과 문화콘텐츠 정책을 제안했습니다. 2026년에는 의성 전통수리 농업시스템 지역에서 대학생들이 게임·웹소설·SNS 숏폼 제작과 마을환경 정비에 참여하는 유사한 청년 활동이 실제로 진행됐습니다. 이번 SGIS 프로젝트는 의성을 첫 사례로 삼아, 다른 인구감소지역의 유휴·저활용 자원에도 적용할 수 있는 정책검토 절차로 확장했습니다.

분석 B. 행정구역별 비교

pandas 집계 후 GeoPandas spatial join으로 시설을 읍면 Polygon에 연결했습니다. 관리주체 분포와 토지 면적당 시설 밀도를 대표 지표로 시각화하고, 읍면 경계와 결과를 Leaflet에서 함께 확인합니다.

토지 면적당 못 개수

읍면 면적을 기준으로 표준화한 시설 밀도입니다. 순위와 실제 값을 함께 보여주어 단순 시설 수와 구분했습니다.

관리주체별 시설 수

관리주체 비교는 별도 관리대장 XLSX 원자료 696건을 기준으로 집계했습니다.

그래프에 마우스를 가까이 대면 세부 집계값을 확인할 수 있습니다. 읍면별 공간 분포는 지도에서 읍면별 시설 밀도 레이어를 ON/OFF하여 확인합니다.

시설 수 비중은 공간 밀도와 분리해 읽도록 구성해, 시설의 분포와 관리 책임의 구조를 함께 비교할 수 있습니다.

재현 순서

  1. 코드 내려받기git clone https://github.com/ssoyoum/Uiseong-Resource-Model.git
  2. 패키지 설치 (Python 3.12)pip install -r requirements.txt
  3. 원자료 준비 행정안전부 인구 python analysis/acquire_population.py WorldPop 참고격자 python analysis/acquire_worldpop.py VWorld UQ151·UQ164·UO601은 로그인 후 내려받아 vworld/에 저장 SGIS 생활권 재조회 시 .env.example을 .env로 복사해 인증키 입력
  4. 전체 실행python analysis/run_competition_pipeline.py마지막 줄 pipeline complete: PASS 확인

원자료 파일은 각 기관의 이용조건에 따라 저장소에 올리지 않으므로 직접 내려받아야 합니다. 원자료가 바뀌면 SHA-256 점검(분석 G)이 실패로 표시됩니다.
